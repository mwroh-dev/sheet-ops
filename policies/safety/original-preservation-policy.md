# Original Preservation Policy

## Purpose

The first live `use` flow must preserve the source workbook.

## Rules

- Source workbooks must not be overwritten.
- Workbook-changing runs must write a new output file.
- Execution must not start before a structured policy decision is written.
- Any policy denial or approval requirement must be recorded as evidence.
- Public package cleanup phases should purge ephemeral runs, re-verify the
  remaining curated material, and keep unfinished work explicit as backlog
  instead of mixing it into current execution.
